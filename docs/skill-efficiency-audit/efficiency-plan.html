Where I was wrong

  • I over-estimated the boilerplate saving by 2-3x. The plan claimed 2,500-4,000 output tokens per artifact. The real shell is 4,938 bytes, and the one I hand-wrote for this very page was 5,051 - so the true saving is about 1,250 output tokens per artifact. Still the largest single per-artifact win, just smaller than advertised.
  • The design.md target was miscalibrated. It fell 34%, not the 50% the criterion named. Everything still in it is a rule the scaffold cannot enforce - semantic markup, decisions in controls, diagram authoring, hygiene. Cutting further would have deleted guidance rather than duplication, so I stopped and reported the miss.
  • My own edits grew SKILL.md by 672 bytes and ate the entire design.md saving, which is why fixed guidance barely moved. I went back and compressed the new prose once I saw the number, cutting it from +1,429 to +672 - largely by deleting a requirements bullet list that duplicated design.md, which brief now prints in the same breath.
The honest summary. Wall clock and round trips improved a lot: prepare went from four blocking calls to one, killed polls are gone, and every idle poll is 4 seconds shorter. Fixed context per session barely moved, at about 2%. The biggest remaining lever is the one option you left unchecked - trimming SKILL.md itself, now 10,040 bytes and by far the largest fixed cost. Decision: how to fix the poll timeout

Finding 2 has two credible fixes and they lead to different failure modes. This one needs your call.

RECOMMENDED

A. Lower the default, document the ceiling

Default --timeout drops to 110s. SKILL.md tells the agent to raise both the harness tool timeout and --timeout when its harness allows.

  • Fails safe on every harness, not just Claude Code
  • Worst case is a cheap idle return, never a killed call
  • Costs one extra idle round trip for slow reviewers

B. Keep 300, document the exact numbers

Default stays 300s. SKILL.md states the literal values: set the Bash tool timeout to 600000 and pass --timeout 570.

  • Zero idle round trips when the agent complies
  • Silently breaks on any harness with a lower ceiling
  • Depends on the model following a prose instruction every time

The plan: four batches of edits to the skill itself

Each phase below is a batch of changes I would make to the artifact-review skill - its CLI (arev.py), its SKILL.md, its playbooks, and one function in server.py. None of them change what the skill does for a reviewer; they change what it costs to run. The Fixed in phase column in the findings table above points at the phase that resolves each finding.

Phase 2 - stop regenerating boilerplate

Goal: kill the single largest output-token cost by shipping the shell instead of describing it.

Finding 1 - boilerplate is regenerated per artifact

Python writes it from a template file, so it costs zero model output tokens. The agent then fills the content region with Edit.

Done when
